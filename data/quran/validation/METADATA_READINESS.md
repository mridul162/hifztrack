## Validation and normalized format

The checker mapped each `(surah_number, ayah_number)` to its canonical order and tested sequential numbering, valid endpoints, and exact once-only coverage. Tanzil start markers use the previous numbered Ayah before the next start as the inclusive end, with `114:6` as the final end. The King Fahd JSON supplied per-Ayah assignments and QUL supplied explicit inclusive ranges. All page candidates covered 6,236 Ayahs without gaps or overlaps. The 1405H ranges cross Surahs on 51 pages and the 1421H and 1441H ranges on 54 pages. Page 48 is the single Ayah `2:282` and page 604 spans `112:1` through `114:6`. [Read-only checker](compare_metadata.py) · [QUL 1421H page ranges](https://qul.tarteel.ai/mushaf_layouts/1)

- Names file. One UTF-8 row per `surah_number` with `name_ar` and `name_latin` and separately versioned source entries for each field. Retain the approved display strings and keep `ayah_count` authoritative in the existing numeric table.
- Mapping files. One row per `juz_number` or `page_number`, with `start_surah_number`, `start_ayah_number`, `end_surah_number`, and `end_ayah_number`. Validate both endpoints before adapting the files to the existing start-only tables. Derive the end on reads by canonical order. Include `edition_id` in the page dataset manifest. Numbered pages exclude covers, reference tables and other front or back matter. Surah headers and unnumbered Basmala lines do not create Ayah coordinates. Al-Fatihah `1:1` remains a numbered Ayah. The current scheme assigns whole Ayahs to exactly one page. Any confirmed split Ayah needs an explicit representation decision before importing that edition.
- Provenance manifest. Keep one record per category with source name, version, URL, path, source SHA-256, usage and attribution, and verification method. For pages include publisher, Ḥafṣ narration, print year, page numbering convention and edition evidence. Preserve the existing transaction and mismatch-refusal behavior when the importer gains these categories. [Database baseline](../../../docs/architecture/DATABASE_DESIGN.md)
